# 🍫 Chocolate Sales & Shipment Analysis — Power BI

An interactive **Power BI Business Intelligence dashboard** designed to analyze chocolate sales, shipments, products, sales team performance, geography, customers, and media analytics.

This project transforms business data into an interactive analytical report that helps users explore performance through KPIs, trends, comparisons, and detailed transaction-level analysis.

# 📊 Dashboard Overview

The repository includes **7 dashboard pages**.

## 🏠 1. Overview

Provides an executive-level summary of business performance, including:

- Total Sales, Boxes, Shipments, Costs, and Profit
- Profitability trends
- Sales by Geography
- Salesperson performance
- Monthly performance

## 🍫 2. Products Analysis

Analyzes product-level performance, including:

- Product sales and profitability
- Product categories
- Top-performing products
- Product performance trends
- Sales distribution

## 👥 3. Sales Team Analysis

Analyzes salesperson performance through:

- Sales by salesperson
- Sales contribution
- Individual performance
- Salesperson comparisons
- Performance trends

## 🌍 4. Geography Analysis

Provides geographical analysis through:

- Sales by country and region
- Geographic distribution
- Regional sales trends
- Interactive map visualization

## 👤 5. Customers Analysis

Analyzes customer and order performance through:

- Total customers and orders
- Customer sales and average spending
- Repeat customer rate
- Order status distribution
- Shipment trends
- Regional profitability
- Customer-level details

## 🔎 6. Detailed Analysis

Provides transaction-level analysis through:

- Order ID and Order Date
- Salesperson, Product, and Category
- Boxes, Sales, Profit, and Profit %
- Order Status
- Monthly Sales & Profit Trend
- KPI Breakdowns and Quick Insights

## 📱 7. Media Analytics

The Media Analytics page analyzes digital campaign performance across social media platforms using the `Campaign Data` and `Platform Summary` tables.

### Campaign Data
- Campaign name, campaign type, date, platform, and creative name
- Impressions and reach
- Clicks, likes, comments, shares, and saves
- Video views and advertising spend

### Platform Summary
- Platform-level impressions, reach, clicks, and engagements
- Click-Through Rate (CTR) and engagement rate
- Views and conversions
- Cost per conversion and advertising spend

### Dashboard Visualizations
- **KPI Cards:** Total Impressions, Total Reach, Total Engagements, Average CTR, and Total Conversions
- **Engagement Distribution:** Engagement comparison across platforms
- **Views Trend by Month:** Monthly views performance
- **Conversions by Platform:** Platform-level conversion comparison
- **Campaign Performance Trend:** Campaign performance over time
- **Top-Performing Ad Creatives:** Comparison of creative performance using impressions, clicks, CTR, conversions, and spend

This page helps analyze audience engagement, compare social media platforms, track campaign performance, and evaluate advertising effectiveness.

# 🎯 Project Objective

The objective was to transform business data into interactive Power BI dashboards that help users understand:

**Sales → Products → Sales Team → Geography → Customers → Profitability**

The Media Analytics page extends the analysis to digital campaign performance and platform-level metrics.

The project focuses on turning data into meaningful insights through data modeling, DAX calculations, interactive visualizations, and dashboard design.
